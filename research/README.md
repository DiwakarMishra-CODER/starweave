# Research notes

Raw, per-realm sourcing work: the "Layer 1" research files the project's own
discipline requires before anything gets written to `data/seed-data.ts` (see
`CLAUDE.md`'s Discipline / hard rules section) - real, named, checkable
sources for who influenced whom, gathered before any confidence tier or
write decision gets made on top of them.

Kept for provenance, not tidiness. Every citation in the graph traces back
to a file in here (or, for the two legacy realms, to `scripts/output/` and
`island-two/` - see `docs/HISTORY.md`). If you're re-opening a realm or
double-checking a claim, start here rather than re-researching from scratch.

For the condensed, current-state summary of what all this research produced,
see `CLAUDE.md`. For the full session-by-session history of how it was
turned into the graph, see `docs/HISTORY.md`.
